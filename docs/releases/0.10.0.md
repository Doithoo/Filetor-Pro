# Filetor Pro 0.10.0

- 文件右键菜单补齐 Cut、Copy、Paste；列表视图的 ⌘X、⌘C、⌘V 使用同一套文件剪贴板逻辑。
- 列表空白处右键提供 Paste、New File、Select All 和 Refresh，并修正双栏时可能在另一窗格新建文件夹的问题。
- New File 提供 TXT、Markdown、CSV、JSON 和无扩展名空文件；同名自动编号，创建后可重命名并撤销。JSON 使用有效的空对象内容。
- 图标和分栏视图同步提供复制、剪切、粘贴及空白处新建文件入口。
- 剪切在 Filetor Pro 内粘贴时才移动文件，沿用冲突确认、任务队列和撤销；取消或部分跳过时保留尚未移动的源文件。跨应用交换标准文件 URL，其他应用仍按其自身粘贴规则处理。
- 保留工具栏配置、工作区和稳定签名身份。
