# Filetor Pro 0.4.0

- 窄窗口下，工具栏收起的搜索与视图切换可以从溢出菜单访问，保留自定义工具顺序和标签。
- 设置按常规、外观、浏览、窗口与工具栏、更新、文件夹权限、关于分类；原有紧凑行高自动迁移，可独立调节列表行高和图标大小。
- 新增扩展名显示选项，隐藏扩展名后重命名仍保留真实文件扩展名。
- 新增本地条件搜索（⌘F），组合名称、类型、扩展名、修改时间和大小，支持当前目录或递归搜索；可编辑或清除条件，搜索不调用 AI 服务。
- 新增路径候选下拉（⇧⌘G），支持中文、空格、相对路径、隐藏文件前缀和 file URL；方向键选候选、Tab 补全、回车打开，文件路径会定位并选择文件。
- 可选原生文件缩略图，默认关闭，按需加载并限制并发和缓存；关闭视图后取消请求，文件修改后刷新缓存。
- 列表、图标与列视图统一提供图像转换及修改时间入口。
- 保留文件夹就地展开、多窗口与标签页恢复、系统 Quick Look/Looq、单一自动更新开关，以及原有应用设置身份和签名更新渠道。

此版本选择性吸收上游 Filetor 1.0.0 的浏览体验改进，并将发布后的路径候选草稿思路重新实现为异步补全。主题系统与 AI 集成留待后续评估。
