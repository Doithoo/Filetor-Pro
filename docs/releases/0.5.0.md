# Filetor Pro 0.5.0

- 工具栏新增 Go To（前往）按钮，点击后在按钮下方展开原生文件夹导航面板，无需记住快捷键。
- 面板可以直接查看当前目录的子文件夹、侧栏收藏和最近访问；点击名称打开，点击右侧箭头继续浏览下一层，并提供返回和上级目录按钮。
- 路径栏每一级文件夹旁增加下拉箭头，可以逐层浏览子目录；打开操作落在对应窗格，移除旧的文件夹放大镜入口。
- 保留粘贴路径、中文和空格路径、Tab 补全以及 ⇧⌘G；输入文件路径时进入其父目录并选中文件。
- 子文件夹列表可滚动查看全部项目，读取在后台执行，关闭或切换后丢弃过期结果；提供空目录、不可用位置和重试提示。
- 最近访问最多保留 20 个本地记录，可清除；仅浏览候选不会加入记录，收藏继续与侧栏共用。
- 首次升级在现有导航按钮附近加入前往按钮，原有工具栏项目 ID、顺序和标签设置保留；以后手动移除或移动按钮的选择会被记住。
- 保留列表就地展开、多窗口和标签页恢复、Looq 系统预览及自己的签名自动更新渠道。
