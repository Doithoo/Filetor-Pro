# Filetor Pro 0.9.0

- 统一列表、图标、分栏视图的压缩解压菜单，明确显示“Compress to ZIP”和“Extract Archive”。
- 检测已安装的 Keka，通过 macOS Services 提供压缩／解压入口，无需加载 Finder 扩展；沿用 Keka 的格式、输出位置和源文件处理设置。
- 各视图均可通过“Open With → Other…”选择其他应用，打开失败时给出反馈。
- 完善 ZIP、TAR 及 GZIP/BZIP2/XZ 压缩 TAR 包的内置解压；单独的 GZIP/BZIP2 文件正确还原为文件，修正复合后缀的输出目录名称。
- 内置压缩解压加入跨窗口任务队列，显示运行状态并支持取消；结果写入独立目录，保留源文件和已有同名内容，失败时清理临时数据。
- 纯 XZ、7z、RAR、加密包和分卷包暂交给 Keka 或其他应用处理；本次不扩展预览格式。
- 沿用现有签名身份、工具栏配置和工作区设置。
