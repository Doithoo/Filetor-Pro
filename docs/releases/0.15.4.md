# Filetor Pro 0.15.4

- 从工具栏和自定义面板移除“窗格布局”。在文件列表或图标视图的空白处点右键可分割窗格；关闭某个窗格的最后一个标签页即可移除该窗格。
- 升级保留其他工具栏项目的顺序、间隔和文字显示设置。旧工作区若有隐藏窗格，可从“显示”菜单选择“显示所有窗格”恢复原布局。

## English

- Removed Pane Layout from the toolbar and its customization palette. Right-click empty space in List or Icon View to split a pane; close its last tab to remove it.
- Other toolbar items keep their order, spacing and label preference. If an older workspace has hidden panes, choose View → Show All Panes to reveal its saved layout.
