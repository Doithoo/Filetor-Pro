# Filetor Pro 0.8.0

- 新增内置 ZIP / 单卷 ZIP64 目录预览：展开目录、查看文件大小与修改时间、识别加密条目，无需解压或依赖 Looq。
- 新增常见代码与文本预览：原生可选择文本、轻量语法高亮、复制与查找。
- 新增 Markdown 阅读/源码切换，展示标题、列表、引用、强调与代码块；图片和链接仅作文字呈现。
- 新增 JSON 格式化/源码切换，保留原始大整数与转义；支持 XML 和二进制 plist 的可读展示。
- 多选文件夹、ZIP、文本和其他文件可在同一窗口逐项查看；未覆盖格式仍使用系统 Quick Look。
- 大文件与超大压缩包明确提示预览限制，后台读取支持取消；ZIP 仅浏览目录，不解压内容。
- 沿用固定签名身份，保留工具栏、偏好与工作区。内置功能仅作用于 Filetor Pro，不替换 Finder 扩展。
