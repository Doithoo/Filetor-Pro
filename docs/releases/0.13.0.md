# Filetor Pro 0.13.0

- 移除自定义工具栏中的 Enclosing Folder，新增 Expand All / Collapse All：一键递归展开或收拢当前窗格的文件夹。
- 展开中可点击 Stop Expanding 停止；收拢、导航或切换视图会取消后台展开，防止旧结果重新打开目录。
- 操作遵守隐藏文件设置，跳过应用包和符号链接；大型目录有明确显示上限及提示。
- 图标模式按钮带有鼠标提示；图标视图、搜索或标签结果中禁用展开操作。View 菜单也可使用相同操作。
- 保留已有工具栏排列、标签文字偏好、工作区和稳定签名身份。已有用户可从 Customize Toolbar 添加两个新按钮。
