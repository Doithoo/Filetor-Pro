# Filetor Pro 0.15.7

- 在展开的子文件夹中解压时，结果现在放在原压缩包旁边。批量选择不同目录的压缩包时，各自就地解压；已有同名文件或文件夹不会被覆盖。

## English

- Extracting an archive in an expanded subfolder now places the result beside the archive. Archives selected across different folders are extracted in their respective folders without overwriting existing items.
