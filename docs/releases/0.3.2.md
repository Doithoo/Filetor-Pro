# Filetor Pro 0.3.2

- 文件夹、压缩包和文件的空格预览统一接入 macOS Quick Look，支持系统已启用的 Looq 等预览扩展。移除原先拦截文件夹和压缩包的内置预览列表。
- 工具栏、右键菜单与空格键使用同一个原生预览窗口；信息面板增加 Quick Look 按钮，方便打开完整预览。
- 图标、列视图支持空格预览；列表选择变化同步更新预览，空格或 Escape 关闭，多窗口之间正确交接预览控制。
- 保留工具栏、工作区及自动更新设置。预览当前文件夹不会改变文件选择。

Looq 需已安装并在系统中启用；具体文件类型由 macOS 选择预览扩展。信息侧栏继续显示元数据和缩略图。
