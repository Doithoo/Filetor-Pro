# Filetor Pro 0.3.0

The maintained fork now uses the Filetor Pro name and standard version numbers.

- Unified the app, menus, settings, installer archive and release channel branding as Filetor Pro.
- Preserved the existing preferences identity, including toolbar items, ordering, labels, sidebar and workspaces.
- Kept the same signed update channel: 0.2.0-personal.2 can upgrade directly without resetting settings.
- Made local builds independent of an installed application by including the licensed application icon in the repository.
- Added a real download/install/relaunch regression for the product and executable rename.
- Retained native folder expansion, independent windows, tabs and file-operation protections.

Requirements: Apple Silicon, macOS 26 or later. The application uses ad hoc signing; macOS Full Disk Access may need to be granted again after updating.

Based on Filetor by David Praznik, under the MIT license. Filetor Pro modifications are maintained by Doithoo.
