# Filetor Pro 0.11.0

- 空白处右键菜单新增水平分割（上下）和垂直分割（左右），支持对任意窗格继续分割，每个窗口最多 16 个窗格。列表与图标视图均可使用。
- 分隔线支持拖动调整比例、双击平分；布局、比例、标签和活动窗格随工作区恢复。空间不足时可滚动查看布局。
- 每个标签始终显示关闭按钮。关闭窗格最后一个标签时移除该窗格，相邻窗格自动填补空位；最后一个窗格的最后一个标签关闭窗口。
- 原有窗格工具栏按钮保留位置和配置，可聚焦当前窗格或恢复完整布局。
- 多个目标窗格时，复制、移动、交换、对比和同步会列出窗格及完整路径供选择，避免操作错位置。
- 兼容旧版本工作区，保留工具栏、收藏、显示偏好和稳定签名身份。
