# Filetor Pro 0.3.1

- Replaced the two automatic-update switches with one “Automatically check for and install updates” setting. Updates download in the background and install on quit; manual checks can still install and restart immediately.
- Migrated existing update preferences once, preserving disabled automatic checks and all toolbar/workspace settings.
- Removed the duplicate New Tab button from the path bar. Each pane now has one button fixed at the right of its tab strip, reachable even with many tabs.
- New tabs activate their own pane, and the strip scrolls to the selected tab.

Requirements: Apple Silicon, macOS 26 or later. Updates retain the same signed release channel and preferences identity.
