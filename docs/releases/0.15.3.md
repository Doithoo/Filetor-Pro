# Filetor Pro 0.15.3

- 关闭最后一个窗口后从程序坞重新打开，在单窗格中选择“水平分割”或“垂直分割”都会得到两个等大的窗格，不再额外出现右侧窗格。
- 旧工作区若保存了一对窗格但仅显示其中一个，首次分割将按所选方向显示这两个窗格，保留原有标签页。

## English

- After closing the last window and reopening from the Dock, splitting a single pane in either direction creates two equal panes. An extra right-hand pane no longer appears.
- If an older workspace saved a pair of panes with one hidden, splitting reveals the pair along the requested axis and preserves its tabs.
