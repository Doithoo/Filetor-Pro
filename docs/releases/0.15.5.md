# Filetor Pro 0.15.5

- 修复窗格重新布局后偶尔停止更新的问题：其他应用完成下载、重命名或删除文件时，当前列表会自动更新并保留仍存在的选中项。
- 连续变更不再反复取消正在读取的目录。回到 Filetor Pro 时，可见窗格会重新核对内容；系统目录监听未能启动时会自动重试。

## English

- Fixed an intermittent stale listing after a pane layout change. Downloads, renames and deletions made by other apps appear automatically, keeping files selected if they still exist.
- Directory reads can now finish during a burst of changes. Visible panes reconcile when returning to the app, and a directory whose event stream could not start is checked again automatically.
