Filetor Personal 0.2.0-personal.2

Personal fork for Apple Silicon Macs running macOS 26 or later.

- Native folder expansion in list view, keyboard navigation and saved expansion state.
- Independent windows, restored tabs, tab reordering and reopen closed tab.
- Safer copying, moving, batch renaming, cancellation and undo/redo.
- Native Sparkle updates from Doithoo/Filetor: check, download, verify, install and relaunch.
- Signed update feed and archives, optional automatic checks and downloads.
- Update restarts wait for active file operations. Existing toolbar and personal preferences are retained.

This personal build is locally code signed and is not Apple notarized. It uses the same com.doithoo.Filetor.personal identity as the previous personal build. Version 0.2.0-personal.1 needs a one-time manual replacement to enable the new updater; subsequent releases install through the application.
